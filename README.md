# Delivery Zone Decision Support

현장 배달구역의 업무부담을 데이터로 비교하고, 일부 배달점을 다른 구역으로 조정했을 때의 영향을 사전에 검토하기 위한 **로컬 기반 의사결정 지원 PoC**입니다.

> 이 저장소의 모든 데이터는 **완전 합성 샘플데이터**입니다.  
> 실제 주소, 수취인, 등기번호, 전화번호, 직원 식별정보, 내부 원자료는 포함하지 않습니다.

## 프로젝트 목표

이 프로젝트는 다음 흐름을 하나의 로컬 분석 도구로 구현하는 것을 목표로 합니다.

1. 주배달점 / 다월 배달결과 / 업무강도 자료 입력
2. 집배구별 배달활동 집계
3. 경계지역 및 인접 후보 탐색
4. 특정 배달점 이관 시 물량 변화 추정
5. 보내는 구 / 받는 구의 업무강도 전후 비교
6. GIS 기반 시각화
7. 관리자 검토용 비교표 및 보고서 생성
8. 필요 시 로컬 LLM을 이용한 **집계결과 설명 보조**

## 핵심 설계 원칙

- **원자료는 로컬 처리**: 실제 업무자료는 외부 서비스에 업로드하지 않음
- **계산과 설명 분리**: 수치 계산은 Python의 결정론적 로직으로 수행
- **LLM은 보조 역할**: 로컬 LLM을 사용할 경우 집계결과의 설명·요약에 한정
- **최종 결정은 관리자**: 시스템이 집배구 조정을 자동 확정하지 않음
- **다월 평균 지원**: 특정 한 달이 아닌 여러 달의 활동량을 비교 가능
- **재현 가능한 분석**: 입력 → 집계 → 시뮬레이션 → 보고서의 계산근거를 남김

## 샘플데이터

샘플데이터는 프로그램 구조 검증만을 위한 완전 합성자료입니다.

- 집배구: `R01` ~ `R04`
- 배달점: `S001` ~ `S032`
- 주소: `샘플로`, `테스트길`, `가상산업로` 등 가상 명칭
- 분석기간: `2099-01`, `2099-02`
- 좌표: 실제 위경도가 아닌 **가상 평면좌표**
- 개별 우편물 ID: `SYN-...` 형식의 합성 ID

실제 기관·직원·고객·주소와 연결되지 않습니다.

## 프로젝트 성격

본 프로젝트는 연구·학습·PoC 목적의 **의사결정 지원 도구**입니다.
실제 업무조정의 최종 결정과 공식 시행은 관련 규정과 내부 절차,
관리자의 현장 검토를 통해 이루어져야 합니다.
